## 📖 Project Overview

This project analyzes an **Online Food Delivery** dataset using **MySQL** to solve real-world business problems.

The objective is to transform raw business data into meaningful insights using advanced SQL techniques such as Window Functions, Common Table Expressions (CTEs), Views, Temporary Tables, Aggregate Functions, CASE Statements, and Subqueries.

---

## 🎯 Project Objectives

- 📊 Analyze restaurant performance
- 💰 Identify revenue-generating restaurants
- 👥 Understand customer ordering behavior
- 🍽 Categorize restaurants based on menu size
- 📅 Analyze monthly order trends
- 📈 Generate business recommendations
